# University DBMS SQL Project

## Project Overview

This project demonstrates the implementation of a relational database management system using MySQL.

The database was designed to manage university-related information including departments, professors, and students. Various SQL concepts were applied to create, manage, and analyze data efficiently.

The project covers database creation, table relationships, data manipulation, query optimization, and reporting through SQL.

---

## Tools Used

- MySQL
- SQL
- MySQL Workbench

---

## Database Entities

### Department

Stores information related to university departments.

### Professor

Maintains professor details including department association, specialization, email information, and joining dates.

### Student

Stores student information and links students with their assigned professors and departments.
